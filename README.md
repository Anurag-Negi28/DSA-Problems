## **2D Array Problems**

### 1. **Wave Print of a Matrix**

- **Description**: Print the elements of a 2D matrix in a "wave-like" manner, traversing columns alternately from top to bottom and bottom to top.
- **File**: [wave_print.cpp](./2D_Array/wave_print.cpp)
- **Key Concepts**: 2D arrays, traversal, alternate column processing.

---

### 2. **Maximum Mango Trees Problem**

- **Description**: Divide a rectangular farm into four parts using one horizontal and one vertical cut such that Ramu gets the maximum number of mango trees after his sisters pick the best three parts.
- **File**: [mango_tree.cpp](./2D_Array/mango_tree.cpp)
- **Key Concepts**: Prefix sum, matrix division, optimization.

---

### 3. **Submatrix Sum Query**

- **Description**: Preprocess a 2D matrix to efficiently calculate the sum of elements in any submatrix defined by its top-left and bottom-right corners.
- **File**: [submatrix_sum.cpp](./2D_Array/submatrix_sum.cpp)
- **Key Concepts**: Prefix sum, range queries, matrix preprocessing.

---

## **Characters and Strings**

### 1. **Character Array Basics**

- **Description**: Learn the basics of character arrays, including initialization, input, and operations like calculating the length of a string.
- **File**: [character.cpp](./Characters%20&%20Strings_01/character.cpp)
- **Key Concepts**: Character arrays, string manipulation, input/output.
